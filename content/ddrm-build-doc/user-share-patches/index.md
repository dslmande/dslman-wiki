# User share - patches

**All credits to Paul Schilling, thank you.**

(source: [https://www.facebook.com/groups/deckardsdream/?ref=nf\_target&fref=nf](https://www.facebook.com/groups/deckardsdream/?ref=nf_target&fref=nf))

In the DD menu, set Keyboard-&gt;TRACKING WIDTH to 4 octaves, and MIDDLE OCTAVE to 5. Also remember to have the volume knob at maximum for best signal to noise ratio.

This was very time consuming, so if you like these presets, please consider PayPal'ing me whatever they are worth to you, at [schillp5@gmail.com](mailto:schillp5@gmail.com)

ENJOY!

**Patch list:** [DD\_CS80\_Presets\_Patch\_List.xlsx](assets/DD_CS80_Presets_Patch_List.xlsx)

CS80 preset bank download: [CS80\_preset\_bank.p](assets/CS80_preset_bank.p)

(after backing up your DD's three .p bank files, unzip this and change the name of the CS80\_preset\_bank.p file to either dd\_bank\_1.p, dd\_bank\_2.p or dd\_bank\_f.p, depending on which bank you want the CS-80 presets to be in)
