## **Specification:**

|   |   |
|---|---|
| **4 Octaven Manual with Aftertouch (FATAR TP9)** | Octave-Shift about 4 Octaves<br>2\* CV-OUT for Pitch ( 0-8V, 1V/OCT )<br>2\* GATE (0/10V)<br>1\* Trigger (0/10V – 2ms)<br>1\* Velocity (0-10V, Dynamik adjustable)<br>Monophone, Duophone and Split-Mode |
| **Sequencer** | 7\* 64 Steps |
| **Arpeggio** | 7 different Modes |
| **Sustain-Pedal** | On/Off |
| **Expression Pedal** | CV (0..10V) |
| **MIDI-OUT** | Note ON/OFF<br>Velocity<br>Sustain<br>Pitchbend<br>CC vom Ribbo & Joystick |
| **XY-Joystick** | each -10 to +10V (Pegel and Offset adjustable)<br>(X) Pitch-Bend<br>(Y) LFO- Control |
| **Ribbon-Bar** | CV (0..4V oder -4V bis +4V)<br>Gate (0/10V)<br>Relative/Absolute/Centered-Mode |
| **LFO** | two Outputs<br>FM Input<br>14 Waveforms<br>Waveshaping<br>Sample&Hold<br>Sync<br>50mHz – 30Hz<br>Delay (fade in) |
| **Transienten-Generator** | Transient-Generator<br>Slew-Limiter<br>Event-Generator<br>Echo-Generator |
